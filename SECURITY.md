# Seguridad

No envíes claves, tokens ni contraseñas en issues o pull requests. Para reportar una vulnerabilidad que
afecte al catálogo o sus validadores, utiliza la función **Report a vulnerability** de GitHub. Los
recursos aceptados siguen siendo datos no confiables: AK Screen verifica las descargas y las procesa con
límites. Un hash confirma integridad respecto del catálogo; no significa que un archivo sea seguro por
sí solo.

Las extensiones ejecutables, código, scripts, DLL, EXE, WASM y paquetes instalables están fuera del
alcance de este repositorio.
